# GMGN 热门币监控扩展

Manifest V3 Chrome 扩展，当前版本 v0.15.0。打开 `https://gmgn.ai/trend` 后自动读取当前筛选榜单；数据库首次建立时静默保存当前可见榜单作为基线，后续发现符合提醒条件的代币时播放声音并记录事件。

扩展不改变 GMGN 的排序、时间段或筛选。它按网页当前顺序遍历完整虚拟榜单，并保存当前排名、成交额及成交额周期。切换链、时间段、排序或筛选不会清除已见记录，任何历史上保存过的合约都不会重复提醒。

所有首次看到的代币都会保存到本地；未提醒过的代币首次进入当前成交额排序前 N 名且满足过滤条件时，才会播放声音、发送桌面通知并写入提醒记录。默认 N=5，支持设置为 1–100；排名直接读取 GMGN 虚拟行的绝对索引，因此用户需要先在 GMGN 页面将成交额设为降序。

弹窗“监控设置”新增最低池子（美元）、最低持有者和最低市值（美元），默认均为 0，表示关闭。启用的条件需要同时满足；页面文本支持 K/M/B、万/亿及千分位数字。数值缺失或低于阈值的币种仍保存，但不响铃、不通知、不触发自动 AI 分析；之后首次满足全部条件时可以提醒一次。点击桌面通知会打开对应代币的 GMGN 页面，多币通知打开第一个，并关闭通知。

代币第一次从完整榜单消失时会记录缺席时间；持续缺席不会反复更新时间。默认连续缺席 7 天后自动删除本地记录，用户可以设置为 1–365 天。没有完整扫描时，使用最后一次在任意扫描中出现的时间补充判断过期；仅时间变化的持久化写入最多每分钟一次。保留期内重新出现只会清除缺席状态，已提醒币种不会重复提醒；过期删除后再次出现则作为新币处理。

扩展读取 GMGN 页面底部的 `Stable / MS / FPS` 连接状态，不使用榜单是否变化来判断卡顿。连接状态持续异常默认 30 秒后自动刷新；15 分钟内最多刷新 3 次，达到上限后锁定自动刷新。恢复为 `Stable`，或关闭再开启自动刷新功能，才会解除锁定。异常等待时间支持设置为 10–300 秒。读不到状态栏时仅提示“无法读取连接状态”，不会触发自动刷新；找不到榜单或关键表头时明确提示“GMGN 页面结构可能已变化”。涨跌幅优先读取对应表头列。

触发提醒后，扩展在弹窗里读取你填写的 AI 地址、协议、模型和 API Key，由插件自己请求 OpenAI 兼容接口，再把结构化结果写回提醒记录。展示内容包括叙事、正负面评价、风险、催化剂、失效信号、观察指标、置信度和来源。

分析结果以“代币背后的故事”为第一层：故事来源、关联人物或事件、为什么此刻走热和时间线。X 舆情只展示带原帖 URL 的真实正面/负面观点，并附作者、账号、短引和互动信息；无法实时检索 X 时明确显示“未完成 X 检索”，禁止用价格涨跌推测社区评价。市场指标和通用交易风险放在次要区块。

API Key 保存在扩展自己的 `chrome.storage.local` 中，不会写入监控导出、错误提示或用量记录。用量能读到接口返回的真实 `usage` 就记录，读不到会标记“中转未返回 usage，无法精确统计”。分析超时不会自动重试，避免重复调用和计费。

为避免干扰 GMGN 页面，扩展在前台只读取当前渲染的行，首次基线也不自动滚动。完整复核每 60 秒执行一次，仅在标签页隐藏或浏览器窗口失焦时运行；用户回到页面时中止完整遍历，不会把中途结果当作完整榜单标记缺席。扫描结果只有实际变化时才写入存储，已见币种表不再重复保存原始行文本和指标表，提醒快照缩短至 240 字符。沿用原存储 key 和 schema，迁移不会因版本变化清空已见记录或强制重建基线。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”。
3. 选择本仓库的 `extension` 目录。

扩展加载后直接打开 GMGN 热门页。页面右上角提供实时面板，浏览器工具栏图标提供全局设置。“打开 GMGN”会使用最近在热门页选择的链；没有记录时打开不带 chain 参数的热门页。已有安装更新后，在扩展管理页点击重新加载，再刷新 GMGN 页面。

## AI 配置

从 v0.14.0 起，插件直接请求 AI 接口，不再需要本地 bridge 后端或配对令牌；v0.15.0 已移除旧 `bridge/` 目录，历史代码可从 Git 恢复。

1. 点击浏览器工具栏里的扩展图标，打开“叙事分析”。
2. 填写接口地址、协议、鉴权、模型、超时时间和 API Key。接口地址默认留空，输入框中的本机地址只是示例，不会自动使用。地址可以只写到 `/v1`，插件会按 chanlun-ai 的方式自动补上 `/responses` 或 `/chat/completions`。`http://` 和 `https://` 都可以，本机、局域网和远程都行；公网 HTTP 地址会显示 Key 明文传输警告，但不阻止保存和连接。
3. 按需打开 Web 搜索和 X 搜索。联网检索只支持 OpenAI Responses。
4. 点击“保存配置”。Chrome 会询问是否允许插件访问该 AI 地址，选择允许。
5. “测试连接”会真的发一次 AI 请求（不是查 `/models`）。开了检索时会要求中转站返回 Web/X 调用证据。测试成功后仍需保存才会用于正式分析。

插件只动态申请你填写的那一个 AI 主机权限，不会默认访问所有网站。长请求由扩展自己的隐藏文档发出，不需要再开一个后端。

“叙事分析”中的“AI 同时分析数量”默认 2，可设置为 1–3；后台任务领取按此上限控制，降低上限时已运行的任务继续完成，后续任务等待空位。未填写 AI 地址和 Key 不影响榜单监控启动；升级前自己保存的有效 AI 地址和 Key 会保留，不会用新的默认值覆盖。

如果填写的仍是原来的 Grok OAuth 账号池地址，账号池没有健康账号时还是会返回 503；这次改动解决的是使用步骤，不是账号池健康问题。

插件弹窗和 GMGN 页面监控面板的“设置”中均提供“手动分析当前榜首”，以及“分析指定 CA”。指定 CA 沿用当前热门榜页面的链，创建带“手动”标识的分析记录并展示完整结果，不要求该代币是新币，也不会播放新币报警。插件刚刚重新加载导致旧页面消息接收端失效时，界面会提示刷新 GMGN 页面，不再显示浏览器英文原始错误。

## 模块边界

- `src/content/adapters`：只按 GMGN 当前页面顺序读取完整榜单。
- `src/content/core`：只编排基线、扫描间隔和监控状态。
- `src/background`：统一拥有历史数据、设置、声音、桌面通知、AI 配置和叙事分析请求。
- `src/content/ui` 与 `src/popup`：只消费状态和发送用户命令。
- `src/shared`：消息协议、配置和无界面业务规则。

本地模块预览地址为 `http://127.0.0.1:4173/demo.html`。

GMGN 页面必须保持打开；系统休眠、浏览器冻结标签页或网络中断时不会继续扫描。本扩展只做榜单发现与提醒，不执行交易。

## 本地验证

使用已有 Node.js 执行 `node --test extension/tests/*.test.mjs`，运行内置测试，无需安装依赖。测试覆盖基线、新币和提醒名次、最低指标过滤、缺席与过期、旧数据迁移、存储去重、AI 并发、通知点击、链记忆、抓取自检和看门狗保护。
