# GMGN 热门币监控扩展

Manifest V3 Chrome 扩展。打开 `https://gmgn.ai/trend` 后自动读取当前筛选榜单；数据库首次建立时静默保存完整榜单，后续出现本地未记录的“链 + 合约地址”时播放声音并记录事件。

扩展不改变 GMGN 的排序、时间段或筛选。它按网页当前顺序遍历完整虚拟榜单，并保存当前排名、成交额及成交额周期。切换链、时间段、排序或筛选不会清除已见记录，任何历史上保存过的合约都不会重复提醒。

所有首次看到的代币都会保存到本地，但只有首次发现时位于当前成交额排序前 N 名的代币才会播放声音、发送桌面通知并写入提醒记录。默认 N=5，支持设置为 1–100；排名直接读取 GMGN 虚拟行的绝对索引，因此用户需要先在 GMGN 页面将成交额设为降序。

代币第一次从完整榜单消失时会记录缺席时间；持续缺席不会反复更新时间。默认连续缺席 7 天后自动删除本地记录，用户可以设置为 1–365 天。保留期内重新出现只会清除缺席状态，不会重复提醒；过期删除后再次出现则作为新币提醒。

扩展读取 GMGN 页面底部的 `Stable / MS / FPS` 连接状态，不使用榜单是否变化来判断卡顿。连接状态持续异常默认 30 秒后自动刷新；15 分钟内最多刷新 3 次，达到上限后锁定自动刷新。恢复为 `Stable`，或关闭再开启自动刷新功能，才会解除锁定。异常等待时间支持设置为 10–300 秒。

触发提醒后，扩展只把链、合约地址、名称、价格、成交额、排名等公开代币数据发送到本机分析服务。插件不保存上游 API Key、不访问 Grok 中转，也不包含提示词、接口兼容或结果解析逻辑。

本地分析服务独立拥有 `GROK_MODELS_BASE_URL`、模型、API Key、Responses/Chat Completions 模式、搜索模式、超时、提示词和解析器。分析结果返回插件后写入提醒记录，展示叙事、正负面评价、风险、催化剂、失效信号、观察指标、置信度和来源。

分析结果以“代币背后的故事”为第一层：故事来源、关联人物或事件、为什么此刻走热和时间线。X 舆情只展示带原帖 URL 的真实正面/负面观点，并附作者、账号、短引和互动信息；无法实时检索 X 时明确显示“未完成 X 检索”，禁止用价格涨跌推测社区评价。市场指标和通用交易风险放在次要区块。

API Key 只保存在权限为当前用户可读写的 `bridge/.analysis-config.json`，该文件被 Git 忽略。日志不记录 API Key、请求正文或代币内容。分析超时不会自动重试，避免重复调用和计费。

为避免干扰 GMGN 页面，扩展只在页面打开时完整读取一次虚拟榜单。前台日常监控只读取榜单当前变化的行；完整复核每 60 秒执行一次，但仅在标签页隐藏或浏览器窗口失焦时运行，因此不会在用户查看页面时自动滚动榜单。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”。
3. 选择本仓库的 `extension` 目录。

扩展加载后直接打开 GMGN 热门页。页面右上角提供实时面板，浏览器工具栏图标提供全局设置。

## 本地分析服务

本地分析服务默认只监听 `127.0.0.1:18761`，不会向局域网开放。插件只调用本机 `/analyze`，本地服务再访问上游中转。

1. 双击 `bridge/start.command`，或在仓库目录执行 `./bridge/start.command`。
2. 打开 `http://127.0.0.1:18761/`，填写并保存上游 AI 配置。
3. 把终端显示的配对令牌填入插件“叙事分析”页，保存连接后测试服务。

配对令牌首次启动时随机生成并保存到被 Git 忽略的 `bridge/.bridge-token`。分析日志位于 `logs/bridge.log`。
如果 Chrome 弹出“本地网络访问”权限，请选择允许。桥接程序更新后需要先在原终端按 `Control+C` 停止旧进程，再重新运行 `bridge/start.command`。
Chrome 142 及更高版本要求先由插件的可见页面触发本地网络授权，后台 Service Worker 才能访问本机服务。因此“保存连接”和“测试服务”会先执行一次不携带代币数据的 `/health` 请求。
实际桥接请求由扩展的 Offscreen Document（后台隐藏文档）执行，避免 Chrome 对 Service Worker 本地网络请求的单独限制；后台只负责任务编排和接收结果。
隐藏文档使用无 30 秒自动关闭限制的响应处理类型，确保带即时搜索的长分析不会中途断开消息通道。桥接客户端断开时会同步取消上游请求，且桥接超时不自动重试，避免重复调用。

插件弹窗和 GMGN 页面监控面板的“设置”中均提供“手动分析当前榜首”按钮。它读取当前筛选和排序下排名第 1 的代币，创建带“手动”标识的分析记录并展示完整结果，不要求该代币是新币，也不会播放新币报警。插件刚刚重新加载导致旧页面消息接收端失效时，界面会提示刷新 GMGN 页面，不再显示浏览器英文原始错误。

## 模块边界

- `src/content/adapters`：只按 GMGN 当前页面顺序读取完整榜单。
- `src/content/core`：只编排基线、扫描间隔和监控状态。
- `src/background`：统一拥有历史数据、设置、声音和桌面通知。
- `src/content/ui` 与 `src/popup`：只消费状态和发送用户命令。
- `src/shared`：消息协议、配置和无界面业务规则。

本地模块预览地址为 `http://127.0.0.1:4173/demo.html`。

GMGN 页面必须保持打开；系统休眠、浏览器冻结标签页或网络中断时不会继续扫描。本扩展只做榜单发现与提醒，不执行交易。
