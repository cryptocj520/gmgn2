# GMGN 热门币监控扩展

Manifest V3 Chrome 扩展。打开 `https://gmgn.ai/trend` 后自动读取当前筛选榜单；数据库首次建立时静默保存完整榜单，后续出现本地未记录的“链 + 合约地址”时播放声音并记录事件。

扩展不改变 GMGN 的排序、时间段或筛选。它按网页当前顺序遍历完整虚拟榜单，并保存当前排名、成交额及成交额周期。切换链、时间段、排序或筛选不会清除已见记录，任何历史上保存过的合约都不会重复提醒。

所有首次看到的代币都会保存到本地，但只有首次发现时位于当前成交额排序前 N 名的代币才会播放声音、发送桌面通知并写入提醒记录。默认 N=5，支持设置为 1–100；排名直接读取 GMGN 虚拟行的绝对索引，因此用户需要先在 GMGN 页面将成交额设为降序。

代币第一次从完整榜单消失时会记录缺席时间；持续缺席不会反复更新时间。默认连续缺席 7 天后自动删除本地记录，用户可以设置为 1–365 天。保留期内重新出现只会清除缺席状态，不会重复提醒；过期删除后再次出现则作为新币提醒。

扩展读取 GMGN 页面底部的 `Stable / MS / FPS` 连接状态，不使用榜单是否变化来判断卡顿。连接状态持续异常默认 30 秒后自动刷新；15 分钟内最多刷新 3 次，达到上限后锁定自动刷新。恢复为 `Stable`，或关闭再开启自动刷新功能，才会解除锁定。异常等待时间支持设置为 10–300 秒。

触发提醒后可自动调用 Grok API 搜索公开资料并分析代币叙事与潜力观察。提醒列表显示一句话摘要，点击后展开宽版详情，分别展示叙事说明、潜力依据、催化剂、失效信号、观察指标、风险、标签、置信度和来源。支持自定义 `GROK_MODELS_BASE_URL`、模型名称和 `XAI_API_KEY`；默认同时使用 `web_search` 与 `x_search` 获取即时网页和 X 信息，遇到不支持 `x_search` 的中转可关闭该工具。

API Key 通过扩展弹窗录入，保存在扩展后台独立 IndexedDB 中，不进入 GMGN 页面、普通设置或 JSON 导出；请求使用 `store:false`。自定义中转域名只在用户保存时申请对应的可选权限，普通 HTTP 仅允许本机地址。浏览器扩展无法防止拥有本机 Chrome 调试权限的人读取密钥。

为避免干扰 GMGN 页面，扩展只在页面打开时完整读取一次虚拟榜单。前台日常监控只读取榜单当前变化的行；完整复核每 60 秒执行一次，但仅在标签页隐藏或浏览器窗口失焦时运行，因此不会在用户查看页面时自动滚动榜单。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”。
3. 选择本仓库的 `extension` 目录。

扩展加载后直接打开 GMGN 热门页。页面右上角提供实时面板，浏览器工具栏图标提供全局设置。

## 模块边界

- `src/content/adapters`：只按 GMGN 当前页面顺序读取完整榜单。
- `src/content/core`：只编排基线、扫描间隔和监控状态。
- `src/background`：统一拥有历史数据、设置、声音和桌面通知。
- `src/content/ui` 与 `src/popup`：只消费状态和发送用户命令。
- `src/shared`：消息协议、配置和无界面业务规则。

本地模块预览地址为 `http://127.0.0.1:4173/demo.html`。

GMGN 页面必须保持打开；系统休眠、浏览器冻结标签页或网络中断时不会继续扫描。本扩展只做榜单发现与提醒，不执行交易。
