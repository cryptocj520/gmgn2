# GMGN 热门币监控

一个运行在 `https://gmgn.ai/trend` 页面内的用户脚本。它直接读取 GMGN 当前榜单，因此会继承网页上的链、周期、平台、关键词、市值、成交额、持有者和风险项等筛选。

## 行为

- 点击“开始监控”后，第一次扫描只建立基线，不提醒。
- 后续榜单出现本地从未记录过的“链 + 合约地址”时，播放三音提醒并加入“新发现”。
- 代币详情、动态指标、首次/最近出现时间保存在浏览器 IndexedDB。
- 声音可关闭或试听；刷新页面后需要再次点击“开始监控”，以满足浏览器声音播放规则。
- 切换榜单周期、类型或应用新筛选时，默认静默重建基线，避免筛选变化造成集中误报。
- 可将全部代币和提醒历史导出为 JSON，也可清空本地记录。

## 安装

1. 在浏览器中安装 Tampermonkey、Violentmonkey 或同类用户脚本管理器。
2. 运行 `npm run build`。
3. 通过本地服务器打开 `dist/gmgn-monitor.user.js`，脚本管理器会显示安装页。
4. 打开 [GMGN 热门页](https://gmgn.ai/trend?chain=robinhood)，右上角会出现监控面板。

本仓库的本地安装地址默认为：

```text
http://127.0.0.1:4173/dist/gmgn-monitor.user.js
```

## 本地验证

```bash
npm run check
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/demo.html`。先开始监控，再点击“模拟新增代币”即可验证新增识别和声音。

## 使用限制

- 监控依赖 GMGN 页面保持打开；系统休眠、浏览器冻结后台标签页或网络中断时不会继续扫描。
- GMGN 如果大幅调整榜单 DOM 结构，脚本可能需要同步更新选择器。
- 本工具只做榜单发现与提醒，不执行交易，也不构成投资建议。
